print()
O comando print() serve para mostrar uma informação na tela.

Exemplos refinados:
print("Olá, mundo!") → Texto na tela: Olá, mundo!
print(100) → Número na tela: 100

"Anotação rápida: Textos para exibir sempre precisam de aspas duplas (\\\"\\\") ou simples (\\'). Mas se for apenas números, pode colocar direto nos parênteses!"

Referência rápida:
Comando: print() | Função: mostrar uma informação
COMANDO: input()
MANUAL — PÁGINA 2
O COMPUTADOR TAMBÉM PODE PERGUNTAR
O comando input() permite que o programa receba uma informação.
Ele também pode apresentar uma pergunta antes de esperar a resposta.

Exemplo:
input("Qual é o seu nome? ")

O computador mostra:
Qual é o seu nome?
E espera que alguém digite uma resposta.

"Anote aí: se o computador fala com o print(), ele escuta e recebe com o input()!"

Referência rápida:
print() → mostrar | input() → perguntar/receber
CONCEITO: VARIÁVEIS
MANUAL — PÁGINA 3
VARIÁVEIS
Uma variável é um espaço utilizado pelo programa para guardar uma informação.

Imagine uma caixa rotulada:
usuario
┌──────────────────────┐
│ Rafael Mendes │
└──────────────────────┘

Podemos guardar uma informação:
usuario = "Rafael Mendes"

E depois recuperar:
print(usuario)

"Dica: O nome da variável é como a etiqueta da caixa (usuario). O valor armazenado dentro dela (Rafael Mendes) pode mudar a qualquer momento."
TIPO: BOOLEANO (TRUE / FALSE)
MANUAL — PÁGINA 4
TRUE E FALSE
Algumas informações representam apenas duas possibilidades.
Ligado ou desligado. Ativo ou inativo. Conectado ou desconectado.

Em Python representamos isso usando:
True e False

Exemplo:
computador_ligado = True (Computador está ligado)
computador_ligado = False (Computador está desligado)

"Atenção! No Python, True e False devem obrigatoriamente começar com letra MAIÚSCULA. Escrever 'true' ou 'false' minúsculo causará erro de sintaxe."
ESTRUTURA: TOMADA DE DECISÃO
MANUAL — PÁGINA 5
FAZENDO O COMPUTADOR DECIDIR
Agora podemos fazer o computador escolher uma ação dependendo de uma condição.

if → significa "se" (if computador_ligado:)
else → significa "caso contrário" (else:)

"Regra 1: O sinal de '=' serve para ATRIBUIR (guardar) valores. Para COMPARAR se algo é igual, você deve usar '==' dentro do if."
"Regra 2 (Condição Oculta): Escrever 'if computador_ligado:' já é o bastante! Como a variável já guarda True ou False, o Python sabe interpretá-la diretamente. Usar '== True' é redundante!"

Tabela de Sintaxe:
• if : significa "se"
• else : significa "caso contrário"
• : : (Dois-pontos) obrigatório no fim da condição para abrir o bloco de comandos!
