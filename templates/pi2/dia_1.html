AMBIENTE DE TREINAMENTO
Página — PRINT
Linguagem utilizada neste terminal:
PYTHON

O comando print() serve para mostrar uma informação na tela do computador.

Exemplo:
print("Olá")

• print indica a ação de exibir;
• O conteúdo do texto fica obrigatoriamente entre aspas.

SINTAXE — PYTHON
"Anotação rápida: Textos para exibir sempre precisam de aspas duplas (\") ou simples (\'). Mas se for apenas números, pode colocar direto nos parênteses!"
SINTAXE — PYTHON
Página — INPUT
O comando input() permite que o sistema receba uma informação digitada diretamente pelo usuário.

Exemplo:
input("Qual é o nome?")

O computador apresenta a pergunta e aguarda a digitação de uma resposta.

Também podemos evoluir o comando armazenando o dado diretamente em uma variável:
usuario = input("Qual é o nome?")
"Se o computador fala com o print(), ele escuta e recebe com o input()!"
SINTAXE — PYTHON
Página — VARIÁVEIS
Uma variável funciona como uma identificação ou caixa usada pelo programa para salvar uma informação que usaremos depois.

Exemplo:
usuario = "Rafael Mendes"

• usuario é o nome dado à variável;
• O sinal = atribui/guarda a informação.

Para exibir o dado salvo:
print(usuario)
"O nome da variável fica à esquerda e o sinal '=' significa ATRIBUIR (guardar) a informação dentro dela."
SINTAXE — PYTHON
Página — Estados
Nem toda informação do sistema operacional é composta por textos longos ou números.

Algumas informações representam apenas duas possibilidades específicas:
• Verdadeiro ou falso;
• Ligado ou desligado;
• Ativo ou inativo.

Para isso, usamos os booleanos:
computador_ligado = True
computador_ligado = False

• True representa verdadeiro;
• False representa falso.

Atenção: Python diferencia maiúsculas de minúsculas. "True" e "False" devem iniciar com letras maiúsculas.
"Atenção extrema: No Python, True e False começam sempre com letra MAIÚSCULA. Escrever minúsculo dará erro!"
SINTAXE — PYTHON
Página — Tomando decisões
O comando if (significa "se") permite que o programa tome uma decisão e execute uma ação somente quando uma condição for verdadeira.

Exemplo:
if computador_ligado:
    print("ESTAÇÃO OPERACIONAL")

• if: comando "se";
• computador_ligado: a condição avaliada;
• : indica o início do bloco de código;
• Recuo/Indentação de 4 espaços define que o comando pertence ao if.

ATENÇÃO:
• = serve para atribuir/guardar um valor.
• == serve para comparar duas informações.
"Lembrete de ouro: Nunca esqueça os dois-pontos (:) ao final do if e do else, e sempre recue (indente) o comando print logo abaixo deles!"
SINTAXE — PYTHON
Página — Caso contrário
O comando else (significa "caso contrário") define o caminho alternativo quando a condição do if não for verdadeira.

Estrutura Completa:
if computador_ligado:
    print("ESTAÇÃO OPERACIONAL")
else:
    print("VERIFICAR ESTAÇÃO")

Lógica de Fluxo:
• if → condição verdadeira → executa primeiro bloco;
• else → condição falsa → executa segundo bloco.

Nota técnica: O primeiro : inicia o bloco do if e o segundo : inicia o bloco alternativo do else. Os comandos subordinados precisam de indentação.
